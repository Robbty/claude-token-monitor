Plan-Tracking aktivieren?

Das Display liest beim Start und alle 60 Sekunden das in ~/.claude/.credentials.json gespeicherte OAuth-Token (das Claude Code sowieso anlegt) und schickt es als Bearer-Header an

https://api.anthropic.com/api/oauth/usage

Damit holt es deinen aktuellen Konto-Auslastungs-Stand (5h-/7d-Fenster). Die Antwort wird 60 s im RAM gecacht und nicht persistiert. Token und Daten verlassen deinen Rechner nicht über den oben genannten Endpoint hinaus.

Du kannst das jederzeit über das ⚙-Menü wieder ausschalten.
